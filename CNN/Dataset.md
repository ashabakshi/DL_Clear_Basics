# CNN - MNIST Digit Classification

## 📁 Dataset

The MNIST dataset (CSV format) has **not been uploaded** to this repository due to GitHub's file size limitations (files exceed 100MB).

## 📥 Download Dataset

You can download the dataset from Kaggle:

🔗 [MNIST in CSV - Kaggle](https://www.kaggle.com/datasets/oddrationale/mnist-in-csv)

Download the following files and place them inside the `CNN/` folder:
- `mnist_train.csv`
- `mnist_test.csv`

## 📓 Notebook

The `CNN.ipynb` notebook contains the full implementation of a Convolutional Neural Network trained on the MNIST dataset.
